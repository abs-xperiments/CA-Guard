# Phase 0 — Research and Decision Gate

## Goal
Validate the market, patent landscape, dataset, technology choices, and research hypothesis before any implementation.

## Required outputs
- refreshed market map;
- prior-art table;
- verified dataset choice and license;
- canonical data schema proposal;
- technology stack with justification;
- architecture freeze;
- evaluation protocol;
- three-month execution sequence;
- list of founder decisions/credentials, if any.

## Exit criteria
No major assumption remains unverified. Any uncertainty is explicitly documented rather than silently assumed.
