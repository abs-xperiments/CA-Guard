# Data Sources Registry

This file is deliberately empty until Claude completes Phase 0 and verifies every external dataset's current license, access method, version, and intended use.

For every dataset record:
- name
- URL
- version/date accessed
- license
- allowed usage
- checksum where practical
- why it is relevant
- preprocessing performed
- whether it is bundled, downloaded at setup, or used only for benchmark evaluation

Current leading candidate: `VynFi/vynfi-journal-entries-1m`.
